# Change plans

Open plans for repository changes, one file per change; fully completed plans move to `done/`.
Each plan follows [the TODO template](../agents/skills/investigate-change/references/todo-template.md),
which owns its authority register, gates and status.

| Convention | Rule |
|---|---|
| Filename | `YYYY-MM-DD_HHMM-<concise-change-name>.md`, from creation time; the prefix is never renamed |
